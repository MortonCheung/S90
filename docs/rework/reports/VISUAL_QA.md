证据目录 `../evidence/stage-11/` 含 `regression.json`、截图、`desktop-regression.webm` 和录屏抽帧 `regression-filmstrip.jpg`。已查看六档线稿、揭幕中段、轮毂、尾灯、座舱和录屏序列。

性能以灯组驻留后的 3 秒 requestAnimationFrame 采样。桌面两档及移动模拟约 60.1–60.4 fps，p95 帧间隔约16.7–16.8 ms。旧版同机位为60.31 fps，新版为60.26 fps。旧14,539,596 B → 新73,364,248 B，局域回环测试下载约69→176 ms。关闭开场动画后新版可见约2.38 s，旧版仍运行裂幕的基线约4.10 s，两者含不同揭幕行为。完整动画和录屏开启的1600测试约10.42 s见到正式界面。73 MB 对弱网有显著影响，已通过真实进度等待和失败重试验证，广域网时长与移动真机帧率仍需实测。

构建压缩体积约 334.84 KB JS / 4.89 KB CSS。修复首次回归发现的虚空热点标签命中、全屏跳转时使用旧画幅、尾灯镜片共用深色玻璃、未知进度游标样式与仅WebGL1检测误判。后续同一套回归通过。
