# 阶段04 · 车模几何与贴图的保真再优化

## 唯一需求

查明当前汽车“塑料、粗糙、廉价”的**模型数据原因**，尽可能保留必要曲率、轮毂、灯组和内饰细节。此阶段只动模型资产及预览对比，不调整灯光和摄影镜头（下阶段再做）。

## 当前证据

- 原始 `volvo_s90_recharge_free.glb` 约368MiB，旧初版 `public/assets/model/s90-opt.glb` 约14.54MB。
- `docs/reports/STAGE-05.md` 记录采用 glTF Transform `--simplify-ratio 0.45 --texture-size 2048`，同时承认“内饰被显著简化”。
- 当前 `useCarAsset.js` 调整材质参数，但原模型与压缩模型的实际高光、法线、贴图差异尚未在同一环境复测。

## 输入确认

优先定位 `source_assets/volvo_s90_recharge_free.glb`，如果不存在可使用用户另外交付的原始模型。**原始 GLB 不在远端 Git 仓库**，不要从旧 M4 随便替换。确实缺失时保留当前模型，标记与原模型的对比为 BLOCKED，继续其它独立阶段。

## 施工步骤

1. 对原始版、现有 `s90-opt.glb` 进行元数据审计：顶点、三角面、材质、纹理尺寸/格式、法线/切线、部件名、尺寸、动画与扩展。确保有相同的坐标系、比例和起始侧视投影。
2. 以固定相机、固定背景与固定灯光创建只读对比页。每一版截取正侧、车头45°、轮毂近景、车灯近景、座舱近景，制作并排对比（不能以两个不同机位对比材质好坏）。
3. 先查几何：车身高光是否出现折线、轮拱/车门接缝是否破裂、车灯表面是否塌陷、轮辐是否损坏。几何质量不通过时应调整简化策略。
4. 在**新输出路径**尝试更保守的减面（参考保留约80%及更小错误阈值，不代表必须使用这两个参数），纹理从较高质量入手，再逐步压缩；不以文件大小最小为唯一目标。
5. 优先保留车漆/车灯/轮毂清晰度；内饰需要时从原模型抽取高精版本或分资源按需加载。模型转换前后检查部件命名和材质映射（例如 `Car_Paint`、`Glass` 等），不能让换色功能失效。
6. 由实际 Chrome/Three.js 渲染效果决定选哪套产物。可以保留外观优化版+内饰高精版，但任何分拆方案不得破坏“单 Canvas/同一叙事”的用户体验。全项目资源不需要硬性压到14MB。
7. 确认原始模型作者许可（CC BY 4.0）信息与修改说明仍在 `docs/ASSET_LICENSES.md`；更新实际压缩记录。

## 命令示例（在工程根目录；先确认 CLI 版本支持这些参数）

```bash
npx @gltf-transform/cli inspect source_assets/volvo_s90_recharge_free.glb
npx @gltf-transform/cli inspect public/assets/model/s90-opt.glb
mkdir -p public/assets/model/candidates
npx @gltf-transform/cli optimize \
  source_assets/volvo_s90_recharge_free.glb \
  public/assets/model/candidates/s90-detail-v2.glb \
  --compress meshopt \
  --texture-compress webp \
  --texture-size 4096 \
  --simplify-ratio 0.85 \
  --simplify-error 0.0003 \
  --palette false --join false --instance true
```

> **不是推荐盲目一次性使用这些参数**：CLI 版本、压缩格式和可用内存须先验证，失败则回退单项压缩并记录。该示例用于展示比0.45更保守的候选策略。可用官方文档：https://gltf-transform.dev/cli 。

## 验收标准

- 车漆外表曲面和车灯、轮毂的局部几何较初版有所改善，近景不可见明显破损；内饰若需展示，材质至少能清晰分辨座椅、仪表台和方向盘。
- 重新优化后的模型大小、解码时间、帧率均记录真实数据；如果质量改善带来成本增加，应提供权衡理由。
- 换色使用的材质名称、坐标与热点位置未被意外改写。
- 原始模型文件只读保留；候选模型都有独立文件名；提供对照图、`STAGE-04.md` 和选型决定。
