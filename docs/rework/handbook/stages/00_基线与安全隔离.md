# 阶段00 · 基线、安全隔离与逐帧取证

## 唯一需求

给已经完成初版的 S90 项目建立可靠可恢复的开发基线，并记录重构前的真实问题。**本阶段不修改任何视觉功能。**

## 必须确认的事实

远端：`https://github.com/MortonCheung/S90.git`（main）；2026-11-03 检查时 HEAD 为 `ae52257295bd...`，执行时必须重新查证。旧 M4 远端仅供参考；`deliverables/` 已有展板 JPG、PDF、演示 MP4，必须保留。

检查这些文件存在并核对实际代码：

`src/opening/Opening.jsx`、`src/opening/useLineart.js`、`tools/lineart/trace.js`、`src/scene/useCarAsset.js`、`src/scene/Studio.jsx`、`src/scene/CameraSystem.jsx`、`src/story/story.js`、`src/detail/DetailPanel.jsx`、`src/styles/global.css`、`src/App.jsx`。

## 施工步骤

1. 确认当前目录是不是 Git 仓库，远端 URL 是否指向 S90；检查 `git status --porcelain=v1`、`git log -5 --oneline` 和 `git remote -v`，记录是否有未提交文件。不要清理用户文件。
2. 拉取远端变更并在**隔离分支/worktree**执行整改。示例：

```bash
# 在确认当前工作树没有冲突、且已知所在仓库后执行
# 若 origin/main 与本地冲突，先审计，不能强制 reset
git fetch origin
git switch -c refactor/s90-visual-storytelling-v3 origin/main
```

3. 记录软件版本：`node -v`、`npm -v`、`npm ls --depth=0`；检查源码是否能以 README 的方式启动。依赖存在时首选 `npm ci`，执行 `npm run build`，日志写 `docs/rework/reports/BASELINE_BUILD.txt`。
4. 在浏览器创建“重构前画面证据”至少覆盖：线稿进度20/50/80%、揭幕首帧、整车、车灯、轮毂、侧面、座舱、车尾、双栏打开/收起、探索模式与移动端。截图需包含时间/进度标签以便复现，不得拿现成广告照片替代。
5. 使用 DevTools 或 Playwright 录制一段从开场到探索的真实操作，标注哪里发生闪烁、镜头偏离及 UI 覆盖。
6. 检查重要资产：`public/assets/model/s90-opt.glb`、`public/assets/lineart/s90-side.svg`、`deliverables`，确认源高精 GLB 是否存在于本地 `source_assets/`。
7. 把原版指标整理到 `docs/rework/reports/BASELINE_AUDIT.md`：SHA、功能、性能、截图名、已知缺陷、可能的风险。分清“观察”与“猜测”。

## 最低可用的浏览器操作示例

如果项目已经有 Playwright，可将以下代码存入独立测试脚本并替换网址；如没有，先依项目现有自动化方式完成。

```js
import { chromium } from 'playwright';
const browser = await chromium.launch();
const page = await browser.newPage({viewport:{width:1600,height:900}});
await page.goto('http://127.0.0.1:5177', {waitUntil:'domcontentloaded'});
await page.waitForTimeout(1000);
await page.screenshot({path:'docs/rework/reports/baseline-loading.png'});
await page.waitForSelector('.site-head[data-dim="false"]', {timeout:60000});
for(const p of [0.20,0.33,0.46,0.59,0.715,0.97]){
  await page.evaluate(p => window.scrollTo(0,(document.documentElement.scrollHeight-window.innerHeight)*p),p);
  await page.waitForTimeout(1000);
  await page.screenshot({path:`docs/rework/reports/baseline-${String(p).replace('.','_')}.png`});
}
await browser.close();
```

> 截图是证据而非审美结论；还须打开看实际图像。若旧版出现卡顿、WebGL 失败等，报告 FAIL 或 UNVERIFIED。
