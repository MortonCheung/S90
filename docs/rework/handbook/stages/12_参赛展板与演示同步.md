## 图片规格验证代码示例

```python
# tools/verify_boards.py — 需要 Pillow
from pathlib import Path
from PIL import Image

for i in (1, 2, 3):
    p = Path(f'deliverables/s90_board_0{i}.jpg')
    assert p.is_file(), f'missing {p}'
    with Image.open(p) as im:
        print(p, im.size, im.mode, im.info.get('dpi'), p.stat().st_size)
        assert im.format == 'JPEG'
        assert im.mode == 'RGB'
        # A3 横向300dpi参考 4961×3508；竖向相应对调
        assert im.size in ((4961,3508),(3508,4961))
        dpi = im.info.get('dpi', (0,0))
        assert min(dpi) >= 299  # JPEG DPI 元数据有取整误差
    size_mb = p.stat().st_size / 1_000_000
    assert 5 <= size_mb <= 6, f'file size {size_mb:.3f}MB outside 5–6MB'
```

> 若组委会“5–6M”按 MiB 而非十进制 MB 计算，需以其实际说明和上传系统测试为准，不擅自混用计量。上面展示的是一套明确、可重复的保守验证规则。
