# 阶段10 · 去无意义小字与失去逻辑的按钮

## 唯一需求

做高端商业产品展厅所需的信息减法与清晰交互，**不修改已经验收的3D场景、镜头和双栏转场**。

## 需要审核的现有元素

- `src/ui/Chrome.jsx`：顶部 VOLVO / S90、数字交互展厅、2026华灿奖、章节导航、章节卡片、SCROLL提示、常驻右下版权小字、顶部进度线。
- `src/opening/Opening.jsx`：`S90 / SIDE ELEVATION`、`SCALE 1:1`、`DIGITAL ATELIER · 2026`、角标、加载说明等。
- `src/detail/DetailPanel.jsx`：小字层级、章节编号、规格表、说明结尾“继续滚动”。
- `src/explore/ExploreLayer.jsx`：FREE EXPLORE、车漆选项、缩放±、复位、返回主线、热点标签和滚动提示。

**不要照单全删。** 分清信息、真实操作和法律必要文字，保留必需项但调整出现时机与位置。

## 期望信息结构

- 开场只看到线稿、中央加载线；有障碍时才显示简短错误说明与重试。
- 揭幕后整车画面可有非常少量品牌/车型标识、一个明确“向下滚动”的引导；不堆“数字交互展厅/2026/ART/DESIGN”等注解。
- 主线各章：主要章节标题+必要的一句解释；右栏详情中再出现可读的说明和少量有依据的信息。
- 自由探索阶段：显示真实有效的车漆切换、重置视角、返回主线等操作；移动端屏幕不堆满按钮。
- CC BY署名及非官方身份说明保留，但放在可访问的“关于/版权”区域，不得抹除来源。

## 施工步骤

1. 建立 `docs/rework/UI_INVENTORY.md`，列举所有可见文字与控件：文件位置、当前状态、用户可理解的功能、最终保留/删除/迁移决定。
2. 每个可点击元素必须验证 `click/touch/keyboard` 后有可观察效果；没有操作目标的装饰性按钮直接删除，不得保留空 click handler。
3. 章节导航如果保留，默认应当低存在感，并用明确的中文章节名；若只是重复底部大标题，删去冗余一套。
4. 消除小于12px但属于主要信息的文字（可根据当前屏幕和字体调整为14–16px）；8–10px只用于可省略的次要元信息，不能靠极小字体制造高级感。
5. 重新安排载入/错误信息，使其可读而不污染主视觉。参考站的克制并非“文字很小”，而是“信息很少”。
6. 用实机鼠标+键盘+移动触屏验证所有操作。必要的版权入口不能隐藏到完全不可找到的位置。
7. 完成移动端布局审查：390×844、窄屏、横向布局，按钮不能挤压汽车主体或遮挡车灯/轮毂。

## 逻辑示例：按模式显隐控件

```jsx
const mode = !opened ? 'opening' : explore ? 'explore' : detailOpen ? 'details' : 'story';
return (
  <>
    {mode === 'story' && !scrolled && <ScrollHint />}
    {mode === 'story' && <ChapterHeading chapter={chapter} />}
    {mode === 'explore' && <ExploreControls />}
    <AboutAndCreditsAccessibleEntry />
  </>
);
```

> 示例仅展示条件逻辑。组件可沿用现有 `Chrome.jsx`/`ExploreLayer.jsx`，无需无理由增建项目框架。`AboutAndCreditsAccessibleEntry` 是待实现的语义占位符，不能假装该组件已经存在。

## 禁止的常见改坏方式

- 将所有说明删光，导致用户不知道如何进入探索模式。
- 不恰当地删除车模作者署名；将法律信息写成不可读的1px文字。
- 用亮色玻璃拟态卡片遮挡汽车，或新增一个“功能汇总”浮层。
- 为减少字数而把车灯/内饰文案改成无意义宣传口号。

## 验收

- 提供新旧相同视角的截图，证明主体更突出；文字与交互清晰。
- 主线、详情、探索三种模式下每个可见按钮都有明确用途，且操作有效。
- 文字没有过小、遮挡或对比度不足的核心信息。
- 保留模型许可和非官方说明，用户能通过可见入口找到。
- 完成 `UI_INVENTORY.md`、`STAGE-10.md`。
