# 阶段05 · 豪华商务轿车的材质与光影

## 唯一需求

在阶段04选定的模型上，改善漆面、玻璃、金属、轮胎和接地阴影，让汽车看起来沉稳、有真实材料层次。**不改变几何简化策略、镜头时间轴或页面布局。**

## 源码定位

- `src/scene/useCarAsset.js::tuneMaterial`：现有 `Car_Paint` metalness 0.82、roughness 0.3，若有 clearcoat 属性才设清漆层；透明玻璃 `opacity 0.66` 且 `transmission=0`。
- `src/scene/Studio.jsx`：1024×512 Canvas 生成的软箱环境，场景 `environmentIntensity=1.05`，多盏高强度 directionalLight，ACESFilmicToneMapping 和曝光约1.04，接地阴影。
- `src/story/paints.js`：四色车漆，`CarModel.jsx` 用 GSAP 插值 RGB。注意材质替换后不可损坏这个入口。

## 设计目标和视觉参考

- 可参考 Volvo S90 品牌图片的材料秩序与克制气质：必须使用有授权的图片做内部对照，不直接放入最终作品。
- 主体应有“车身大面积连续高光 + 少量细密边缘高光”，而不是平均发亮或塑料白色漫反射；黑色车漆同样应能看见腰线和灯组。
- 玻璃能够反射灯箱和环境，同时让车内有合理可读性；金属镀铬呈细长亮带，轮胎维持橡胶哑光；接地影自然地压住汽车。

## 施工步骤

1. 建立固定比较机制：正侧、前45°、灯组、轮毂、座舱、车尾视角，所有候选用相同的 renderer、模型和曝光，否则无法归因。
2. 读取材质类型和纹理通道（sRGB 仅用于 color/albedo/emissive 颜色贴图；roughness/metalness/normal/AO 数据贴图不要强制设 sRGB）。先检查当前 `useCarAsset.js` 把任何 `material.map` 设 SRGBColorSpace 是否与 glTF 实际色彩空间一致，避免误操作。
3. 确认车漆是否真的是 `THREE.MeshPhysicalMaterial`，不是只靠 `if ('clearcoat' in material)` 产生了原地无效果的设置。若不是，谨慎复制当前参数/纹理为物理材质，保持 `name='Car_Paint'`、`map`、`normalMap`、`roughnessMap` 和 `metalnessMap` 等引用。
4. 优先调整环境反射的**形状**：一条顶部长软箱、侧面渐变条光、较弱的边缘光，比单纯增大方向光 intensity 更容易出现汽车广告中的连续高光。
5. 再针对每种材质分别微调，避免“一键全局加反射”；车漆清漆层粗糙度不能低到出现刺眼反光点，玻璃不能不分正反面都透明得像塑料。
6. 地面与背景采用中性暖灰系，不做赛博环境和杂乱模型；避免地面反光压过车身。
7. 每次修改后拍摄相同角度图，保留至少三个候选及最终决定。检查四色车漆在不同视角的亮暗表现，验证色彩切换动画可逆。
8. 性能控制：低端设备可以降低阴影分辨率/高成本透明效果，但不能让旗舰桌面效果退化到初版粗糙程度。

## 示例代码：车漆物理材质（按真实贴图确认后使用）

```js
import * as THREE from 'three';

export function upgradePaintMaterial(original) {
  // 仅作用于 Car_Paint，不随意转换所有材料
  if (original?.name !== 'Car_Paint') return original;
  // MeshPhysicalMaterial 也支持从标准材质复制公共属性；逐一核对贴图。
  const next = original.isMeshPhysicalMaterial
    ? original.clone()
    : new THREE.MeshPhysicalMaterial().copy(original);
  next.name = original.name;
  next.metalness = 0.75;     // 初始调校值，不是固定验收目标
  next.roughness = 0.28;
  next.clearcoat = 0.85;
  next.clearcoatRoughness = 0.09;
  next.envMapIntensity = 1.0;
  next.needsUpdate = true;
  return next;
}
```

注意：如果同一个材质引用被多个 Mesh 共享，更换材质时必须**统一替换所有引用**，否则某些车门颜色无法跟着变化。若原始模型使用 KHR_materials_clearcoat，优先保留作者参数作为基线，而不是不加比较地覆盖。

## 失败模式与退路

- 高光断裂：先看几何/法线是否已损坏，返回阶段04的候选模型评估，不通过过曝来掩盖。
- 玻璃太白/太透明：复查材质的 front/back、depthWrite 和环境，而不是直接 opacity=0。
- 帧率骤降：定位 ContactShadows、透明材质与环境贴图的 GPU 成本，再针对移动端降级。
- 完成模型材质替换后，测试 `CarModel.jsx` 的车漆动画能否找回目标 `Car_Paint`。

## 验收

- 同机位新旧对照能看到更清晰的车体曲率、高光和金属/玻璃分层，而不是仅整体更亮。
- 黑、白、蓝、棕四种色漆均不过曝且形态稳定。
- 车灯、轮辐、门把手和车窗均可辨；阴影没有明显漂浮。
- 桌面和移动仿真性能有实测记录，产出 `STAGE-05.md`，不宣称全设备已60fps。
