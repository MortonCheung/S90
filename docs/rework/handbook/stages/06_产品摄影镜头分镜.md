# 阶段06 · 重做“有目的的汽车摄影机”，而非随机漂移

## 唯一需求

仅重构叙事主相机的运动语义与取景构图。不要调整详情 UI 空间（下一阶段做），也不要另建车模或多 Canvas。

## 现有问题与来源

`src/story/story.js` 现在有9个 `CAMERA_KEYS`，统一对 pos/target/fov 做 Hermite 插值；`CameraSystem.jsx` 每帧采样 `sampleCamera(stateRef.current.smooth, aspect)`。数学上连续，但没有明确的“到位、停顿、阅读、离开”分镜机制。`CAMERA_KEYS` 中 cabin 机位 `[-3.9,1.2,1.1]` 仍在外侧，座舱将另于阶段09处理。

参考： https://spykercars.com/c8-preliator （用户提供的30秒录屏）； https://illoca.unseen.co （到点后展开内容）。重点学习**相机关注什么、何时稳定、何时继续**，不要复制预渲染视频素材。

## 实施步骤

1. 制作只在开发模式可用的**镜头调试页/面板**：显示当前 progress、相机位置、target、FOV、目标物世界点、投影到屏幕的像素位置、距离/遮挡。生产环境绝不保留调试 UI。
2. 在模型坐标中提取灯、轮、腰线、尾灯的真实目标点。若能按 Mesh 名称检索部件，优先 `Box3.setFromObject` 获取中心；否则依据模型截图人工标注，保留截图证据。
3. 用“入场→稳定展示→离场”的区间代替每一章节都持续移动；用独立的 shot 数据源驱动相机而非多个组件争夺 camera.position。
4. 相机和目标点的移动速率要协同：位置可以沿轨迹走，但目标不能猛地从车灯跳到车轮。对关键转向点计算朝向变化及速度，有必要时插入稳定的过渡关键帧。
5. 切换 FOV 要谨慎：突然改变视角会产生“拉伸/乱晃”感。常规车型展示优先维持相近焦段，仅局部特写变化。
6. 做镜头安全检测：车身表面穿越、近裁剪、显著裁切关键部件、目标点移出可阅读区；移动端采用单独构图偏移，而不是一味拉远以致汽车很小。
7. 整车叙事必须可逆：向上滚动时严格回到前一视角；停止滚动后镜头在平滑收敛后应稳定，不发生无限慢漂。

## 可改造的最小区间采样示例

```js
const clamp01 = x => Math.max(0,Math.min(1,x));
const ease = x => { const t=clamp01(x); return t*t*(3-2*t); };
const mix = (a,b,t) => a+(b-a)*t;
const vMix = (a,b,t) => a.map((n,i)=>mix(n,b[i],t));

// 每一段必须由真实测量的 camera pose 构成；hold 区间保持不动
export function sampleMoveHoldLeave(p, enter, hold, leave, p0, p1, p2) {
  if(p<=hold[0]) {
    const t=ease((p-enter[0])/(hold[0]-enter[0]));
    return {pos:vMix(p0.pos,p1.pos,t),target:vMix(p0.target,p1.target,t),fov:mix(p0.fov,p1.fov,t)};
  }
  if(p<=hold[1]) return p1;
  const t=ease((p-hold[1])/(leave[1]-hold[1]));
  return {pos:vMix(p1.pos,p2.pos,t),target:vMix(p1.target,p2.target,t),fov:mix(p1.fov,p2.fov,t)};
}
```

此示例只用于说明局部“运动/停留/离开”的数学规则，不应孤立复制成重复的 camera controller。必须在 `story.js` 维护**单一采样器**，`CameraSystem.jsx` 仍是唯一写入真实相机的位置。

## 验收（真正的摄影机标准）

- 车灯/轮毂镜头在1600×900画面内具有清晰的视觉主体（提交截图并列出目标的画面占比，不只写坐标）。
- 侧面视角可以完整观察腰线、车轮，主体不小得像缩略图。
- 任何章节暂停后，镜头能稳定停在目标，读者可以认出当前展示哪个部位。
- 30%→60%→30%滚动复位时，图像和相机姿态稳定，允许细小数值误差但不能硬切。
- 相机不穿越实体车壳、地面、不可透明的车窗；座舱内穿越只在阶段09按专门规则处理。
- 存档每个稳定镜头和至少一段正反向浏览视频，`STAGE-06.md`。
