# S90 · 视觉叙事整改施工包（v3）

> 适用对象：`https://github.com/MortonCheung/S90.git` 的**已有工程**，不是新建项目。
> 基准审查提交：`ae52257295bdb9e84b6926a498cf165b7bc24675`（2026-11-03），执行时必须重新查询远端 HEAD，不能假定它没有变化。
> 施工目标：修复用户已经指出的视觉与交互问题；保留现有可运行功能与参赛交付物。

## 使用方式（一次启动，Agent 内部分阶段自动执行）

1. 将**本施工包**放在 S90 工程根目录旁或根目录 `design-rework/` 下，不能覆盖已有 `docs/reports/`。
2. 给 Agent 发送 `AGENT_START.txt` 中的整段话。无需逐阶段手动发命令。
3. Agent 先阅读 `00_MASTER_CONTROL.md`，随后一次只读一个 `stages/*.md`，依序完成、测试、记录并自动进入下一阶段。
4. Agent 只有遇到需要登录/授权、不可逆破坏、缺失原始模型且无法替代等真实硬阻断时才允许暂停相应任务；可以继续执行独立任务。
