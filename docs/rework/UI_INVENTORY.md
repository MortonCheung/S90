# v3 界面清单

- Opening：移除框角、比例/日期标注和加载状态小字。中线保留真实进度的无障碍语义。失败时显示可读提示和重试。
- Chrome：VOLVO S90 保留为返回展厅起点的按钮。移除顶部竞赛注释、重复章节卡和独立进度线。章节名收入可键盘操作的章节菜单，关于入口放置非官方说明、车模作者与许可。
- DetailPanel：保留清楚的部件名称、画面可核对的一段说明和座舱概念配色。移除重复编号、英文标签、规格表和尾部滚动提示。
- ExploreLayer：保留 360° 拖动、四种车漆、可见热点、重置视角及返回。桌面保留拉近/拉远，窄屏收起这两个快捷键。隐藏热点不参与 Tab 顺序。
- 字号与焦点：正文采用 15–16px，桌面标题最大 46px。控件 14px，触屏菜单/底栏按钮目标至少 44px。信用入口在桌面与移动端同一位置。
