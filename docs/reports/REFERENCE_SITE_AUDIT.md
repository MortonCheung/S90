# 参考网站取证与机制分析（阶段 01A）

日期：2026-11-03
执行：主控（Playwright 1.64.1 + Chromium 1248，Metal 后端；ffmpeg 抽帧）
范围：Heron AI、Spyker C8 Preliator、illoca、旧车展 Demo
边界：只做观察、截图与网络取证；**未复制任何参考站源码、设计资产或摄影素材**。下文所有机制判断都标注证据与置信度，未验证处不写成事实。

| 项 | 实测 | 结论 |

证据目录：`reference/audit/<site>/`（截图、`evidence.json`、`requests.txt`、`recording/`）。

## 1. Heron AI — https://heronaiapp.com

**取证**
- `t-1200.png`（加载 55%）、`t-3200.png`（100%）、`t-7000.png`（首屏完成态）。
- `recording/f06.jpg`（59%）、`f16.jpg`（揭幕完成）、`f20.jpg`（稳定态）。
- `evidence.json`：页面高度 900（单屏，无滚动叙事）；`<video>` 数量 **0**；`<canvas>` 1 个（1440×900）；资源以 webp/png/js 为主，无图片序列编号请求。

**观察**
1. 加载态是一张建筑立面**线稿**，中央有一条贯穿全宽的**红色水平规则线**，线左端标百分比（55% → 59% → 100%）。
2. 线稿从 55% 到 100% 不是“逐笔生长”：外轮廓在 55% 时就已完整，100% 时增加的是窗框、栏板、阴影等内部层次与线宽——更像按进度切换/叠加的**分层图像**或整体显影，而不是 stroke-dashoffset 逐笔。
3. 100% 后，线稿在同一位置被**成品插画**替换（f16），页面其余 UI（导航、标题、正文）随后淡入；没有看到中线向上下裂开的动作。
4. 单屏站点，无滚动驱动；canvas 只承担颗粒/插画绘制，不是 WebGL 场景。

**机制判断**
- 加载进度 = 预加载管理器（图片/字体/脚本）汇总百分比；红色横线是固定位置的版式元素，不是进度条本身（55% 与 100% 时横线 y 坐标都在画面 49% 处）。
- “揭幕”是**同位交叉淡化**（crossfade），置信度中高（帧间对比 + 无 transform/clip 痕迹可采）。
- 线稿层可能是 SVG 或位图分层，置信度中；无法从产物确认，故不作为可复制结论。

**对 S90 的取舍**
- 采用其“**线稿先建立、真实画面后到位、两者严格同位**”的叙事逻辑；
- 不采用其交叉淡化，改为用户要求的**中央水平线上下裂开**：两片纸各持同一份 SVG，`clip-path` 分半屏，GSAP `yPercent ∓50` 位移，底层是同一 Canvas——因此揭幕瞬间 3D 车与线稿共享同一投影，天然对齐；
- 线稿采用**逐笔生长**（stroke-dashoffset），与本参考的显影方式不同，原因是我们有真实 3D 模型可投影出拓扑一致的边线，逐笔更贴合“设计图纸被画出”的语义。

## 2. Spyker C8 Preliator — https://spykercars.com/c8-preliator

**取证**
- `reference/audit/spyker/top.png`、`scroll-025/05/075/095.png`；`recording/f01..f30.jpg`。
- `evidence.json`：文档高度 **42,199px**（超长滚动）；`<video>` 数量 **0**；`<canvas>` **5 个**，其中 4 个为 1440×900 全屏、1 个 28×24；网络记录以 JS 为主，未见 mp4/webm 请求。
- headless 首屏出现黑场与 “02” 计数（`scroll-05.png`），说明其首屏依赖真实 GPU/媒体权限，自动化环境未完全复现。

**观察**
1. 录屏显示：全屏摄影画面（绿色 C8 停在别墅前）+ 右侧文字栏，滚动时画面推进、段落切换；随后出现双栏（左图右文）的阅读段。
2. 画面是**连续的电影式镜头**（同一场景内视角/主体位置变化），不是硬切轮播。
3. 未见 `<video>`；4 个全屏 canvas 同时存在，说明每个章节可能是独立 WebGL 场景或共享渲染器的多画布布局。
4. 网络侧未捕获到视频分片，但 headless 环境可能未触发媒体加载，**不能据此断言“没有视频”**。

**机制判断**
- 高置信：滚动进度驱动、章节化、双栏阅读段、返回全屏。
- 中置信：画面由 **WebGL/Canvas 实时渲染**（多 canvas + 无 video 元素）；也可能是 canvas 上绘制的视频纹理或图像序列，现有证据无法区分。
- 低置信：具体是预渲染视频、图像序列还是实时 3D——**不下结论**，这正是本项目要避免的“凭猜测认定技术”。

**对 S90 的取舍**
- 采用“滚动即时间轴、镜头连续推进、到点进入双栏阅读、读完回到全屏”的结构；
- 不采用其多 canvas/多场景切换：S90 坚持**单 Canvas、单模型、单相机**，避免章节切换时的上下文开销与硬切；
- 双栏用**投影矩阵镜头平移**（lens shift）而非移动相机，保证车身在左栏的构图不被裁切，退出时反向插值，滚回即恢复。

## 3. illoca — https://illoca.unseen.co

**取证**
- `reference/audit/illoca/top.png`、`scroll-025/05/075/095.png`、`evidence.json`。
- 页面高度 900（单屏交互）；`<video>` 0；`<canvas>` 1 个 2160×1350；资源含 **56 张 jpg、4 个 glb**。

**观察**
1. 单屏建筑可视化：镜头在场景中移动，接近某个构件后出现说明文字/细节层，画面继续缩放并重排版式。
2. 反向滚动能回到上一状态，未见整页刷新。
3. 4 个 GLB + 单 canvas + 大量 jpg，符合“实时 3D 场景 + 贴图/背景图”的组合。

**机制判断**
- 高置信：单 Canvas 的实时 3D（GLB 资源 + WebGL 画布）。
- 中置信：镜头位置触发局部详情层、布局随状态重排；反向滚动由同一时间轴回放，而非重新加载。
- 未验证：其相机是沿样条还是关键帧插值——无源码，不宣称。

**对 S90 的取舍**
- 采用“到达点触发详情、反向滚动可逆、退出后继续运动”的状态机；
- S90 的相机用**一条统一进度轴**上的 Catmull-Rom 采样（`sampleCamera`），正向/反向都只是 t 的增减，天然可逆；
- 详情层用 DOM 覆盖层（可读性、可访问性优于画在 canvas 里），3D 只做构图变化。

## 4. 旧汽车展示 Demo — https://demo.morton.xin

**取证**
- `reference/audit/demo/top.png`、`evidence.json`、`requests.txt`。
- `<video>` 0，但资源含 **4 个 mp4**；canvas 仅 300×150（`hover-video`）；页面高度 900。

**观察**
1. 以视频/贴图为主的展示页，交互是“悬停播放片段”，没有统一的 3D 相机。
2. 页面内车辆切换/模式切换是**硬切**：不同媒体资源直接替换，没有共享的过渡状态。
3. 无真实 360° 模型实例，热点/换色依赖预渲染素材。

**机制判断**
- 高置信：视频驱动、硬切换；不存在单模型连续相机。
- 这正是本项目要避免的反例。

**对 S90 的取舍**
- 不做“每章一段视频”的拼接；全程一个 GLB、一台相机、一条时间轴；
- 章节之间靠相机连续运动过渡，详情靠镜头平移与 DOM 面板，自由探索靠同一相机的 Orbit 接管 + 0.85s 位姿混合，**没有页面级硬切**。

## 5. 横向结论（可直接执行的约束）

| 结论 | 证据 | 在 S90 的落地 |
| --- | --- | --- |
| 开场必须“线稿与实物同位” | Heron f16 同位替换 | 线稿由同一相机投影生成；实时缩放按 `H_viewport/viewHeight` 对齐，实测 4 处轮廓差 0–3px |
| 滚动是唯一进度源 | Spyker 42k 高页面；illoca 单屏镜头 | 原生 `scrollY / (scrollHeight - innerHeight)`，无 GSAP ScrollTrigger 的 pin（避免布局抖动） |
| 详情不能靠切场景 | illoca 4 GLB / Spyker 多 canvas 的复杂度反例 | 单场景 + 投影平移；详情开合只改 `detailFactor` |
| 反向必须可逆 | illoca 反向恢复 | 所有状态都是 t 的纯函数；面板开合由 t 的区间决定 |
| 拒绝硬切 | Demo 的反例 | 唯一的状态切换是 explore 的 0.85s 位姿混合 |
| 技术声明必须有证据 | Spyker 的 canvas/video 歧义 | 展板只写“单 Canvas / 单模型 / 滚动叙事 / 预加载门槛”，不写“实时物理”等无证据话术 |
