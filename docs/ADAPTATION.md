# 桌面端与移动端适配说明

## 断点
- 桌面基准：1600×900（同时验证 1440×900、2400×1350）。
- 移动基准：390×844（iPhone 14 逻辑分辨率），断点 `max-width: 860px`。

## 布局变化
| 元素 | 桌面 | 移动（≤860px） |
| --- | --- | --- |
| 章节索引 rail | 右侧固定，6 章 | 隐藏 |
| 详情面板 | 右侧 520px / 40vw 双栏 | 底部抽屉 46vh |
| 相机 | 车左移 38% 让位 | 车左移 12%，上移 24%，并后拉 16% |
| 探索工具条 | 底部居中单行 | 左右 16px，自动换行，车漆名称隐藏 |
| 署名 | 右下 | 隐藏（保留在文档与展板） |
| 开场线稿 | 视高 3.362m | 按 `H_viewport/viewHeightFor(aspect)` 等比缩放 |

## 竖屏构图
严格正侧在竖屏必然呈横向带状：390 宽时车长约 327px、高约 93px，位于画面中部。这是“正侧 + 完整车身”的几何结果，不是裁切错误；文字与索引因此下移，形成海报式留白。

自由探索与详情在窄屏额外后拉：`narrowPull = 1 + 0.32 * smoothstep(0.9, 1, t)`，保证整车在画面内。

## 触屏
- 探索态：单指拖动旋转，双指缩放交给页面滚动（OrbitControls 关闭 zoom/pan）。
- 详情：随页面滚动进入/离开，无额外手势。
- 热点：44px 可点区域由按钮 padding 保证；圆点视觉 12px。

## 实测
- 390×844：揭幕完成、无横向溢出（`scrollWidth ≤ innerWidth + 1`）、详情抽屉不遮车、工具栏不溢出。
- 1600×900：52fps（headless Chromium + Metal）。
- 未测：真机 Safari、低端 Android、横屏切换后的重新布局（UNVERIFIED）。
