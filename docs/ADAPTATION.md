# v3 桌面与移动适配

## 布局与构图

- 桌面布局大于 860 CSS px 时，独立详情列从右侧打开，画布宽度同步变化。1600×900 灯组驻留的画布实测为 1080×900。
- 860 CSS px 及以下，详情使用下方独立网格行。390×844 灯组驻留的画布实测为 390×464。短横屏用较浅的详情行，正文可独立滚动。
- 画布调整时主相机使用实时宽高比重构取景。正侧开场用同一投影定位线稿和三维车身；移动端按画幅等比容纳车长。
- 章节、关于、返回和车漆可用触摸或键盘按钮操作。探索支持拖动旋转及按钮缩放。可见热点参与 Tab 顺序。

## 验证范围

- Chrome 桌面 1600×900、1440×900，移动模拟 390×844。阶段10补测 320×680 竖屏及 844×390 横屏。
- 三个主测尺寸通过开场、反向恢复、双栏变化、座舱、换漆及探索返回。详情触发、布局几何和截图见 [阶段07](rework/reports/STAGE-07.md)、[阶段10](rework/reports/STAGE-10.md) 与 [全链路复测](rework/reports/VISUAL_QA.md)。
- Safari、iOS、Android 真机帧率及低内存表现为 UNVERIFIED。
