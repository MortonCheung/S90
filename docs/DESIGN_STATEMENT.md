# 数字媒体设计说明 · Volvo S90 数字交互展厅

## 1. 作品定位
以一辆五米级豪华商务轿车为对象，做一个“可被阅读”的数字展厅：不是配置表，也不是特效演示，而是一段由滚动控制的连续镜头，最后交还给用户自由观看。

赛道：2026 华灿奖 · 数字媒体设计（交互界面 / 网页体验）。
形态：桌面浏览器为主，移动端可用；单页应用，无后端。

## 2. 创意概念
**静谧的秩序。**
S90 的设计语言靠比例、水平线和材质，而不是夸张的型面。页面因此采用纸、墨、铜三种基调：纸是展厅，墨是线稿与文字，铜只出现在索引与强调处。没有赛博渐变、没有无意义的小字、没有与车无关的卡片。

开场把“设计图纸”作为叙事起点：一张严格正右侧视的线稿被逐笔画出；同一时刻，真实三维模型在纸下并行加载。就绪后，中央水平线向上下裂开，露出与线稿同位置、同轮廓的真实车模——从图纸到实车的第一次“显影”。

## 3. 交互结构
1. **开场（0–1 屏）**：线稿生长约 3.8s；模型真实字节进度；两者都完成才允许揭幕。
2. **主线（约 8.6 屏）**：原生滚动驱动一条统一时间轴，相机连续环绕，依次经过整车、灯组、轮毂、侧面、座舱、车尾。
3. **详情（5 段）**：滚动进入区间时，全屏自然转为“左车右文”双栏；相机不转向，只做投影平移，保证车身完整；离开区间即收起。
4. **自由探索**：尾段镜头连续拉远，0.85s 位姿混合后交给 OrbitControls；可 360° 旋转、缩放、切换 4 种车漆、点击 5 个部件热点。
5. **返回**：工具条“返回主线”或 ESC，回到 0.86 进度继续叙事。

## 4. 技术方案（有证据的部分）
- React 18 + Vite 6 + React Three Fiber + Three.js r170 + GSAP。
- **单 Canvas、单模型实例、单主相机**；模型 14.54 MB（源 386.35 MB，Meshopt + WebP 2048 + 简化 0.45）。
- 线稿由同一相机对同一模型做边线投影生成（921 条路径），因此揭幕时与 3D 轮廓差 0–3px（1600×900 实测）。
- 滚动为唯一进度源；所有章节/详情/探索状态都是进度 t 的纯函数，因此反向滚动天然可逆。
- 详情用投影矩阵平移（lens shift），不是移动相机或切换场景。
- 失败路径：模型加载失败显示可读错误与“重新载入”，重试成功后可正常揭幕。

## 5. 视觉规范
- 纸 `#EDE9E1`；墨 `#111316`；铜 `#8B6A47`；车漆四色：曜石黑 `#15171B`、水晶白 `#E9E5DC`、峡湾蓝 `#2C4055`、暖铜棕 `#6B5543`。
- 中文标题宋体，正文无衬线；字号层级 1.35 倍递增；行高 1.9–2.05。
- 网格：左右 190px（A3 展板）/ 页面 48px；章节索引固定在右侧，详情时隐藏。
- 运动：只有相机、线稿、幕布三类运动；时长 0.85–1.55s，缓动统一为 `cubic-bezier(.22,.61,.36,1)`。

## 6. 应用场景
- 车展/展厅触屏或大屏的车型叙事；
- 品牌官网的车型章节；
- 设计评审中的“线稿—实车”对照演示。
本项目为非官方概念设计，仅用于竞赛展示，不代表 Volvo 官方。

## 7. 边界与未完成

- 未实现 WebGL 不可用时的静态回退；键盘全流程走查未完成。
