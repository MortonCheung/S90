# 交互流程图说明

> 本页为初版历史记录。当前 v3 以[新版参赛 PDF](../deliverables/v3/s90_interaction_flow.pdf)为准。

## 主流程

```
[进入页面]
   │
   ├─ 线稿 SVG 载入 ──► 921 条路径逐笔生长（约 3.8s）
   │
   └─ GLB 载入（真实字节进度）──► 解析 ──► 首帧编译 ──► ready
                                   │
              drawn && ready ──────┴──► 中央水平线上下裂开（1.55s）
                                   │
                             [解锁滚动]
                                   │
        scrollY / (scrollHeight - innerHeight) = t
                                   │
   t ──► sampleCamera(t) ──► 相机位姿（连续、可逆）
   t ──► detailState(t)  ──► 双栏详情（5 个区间）
   t ──► chapterAt(t)    ──► 章节索引
                                   │
                     t ≥ 0.96 ─────┴──► 自由探索
                                   │
              OrbitControls（旋转 / 缩放 / 车漆 / 热点）
                                   │
              返回主线（滚到 0.86）/ ESC ──► 0.85s 位姿混合回时间轴
```

## 状态机（互斥）

| 状态 | 进入条件 | 退出条件 | 相机归属 |
| --- | --- | --- | --- |
| opening | 页面加载 | drawn && ready && 揭幕结束 | 固定开场位 |
| story | 滚动解锁 | t ≥ 0.96 | 时间轴（sampleCamera） |
| detail | t ∈ 任一详情区间（story 内） | 离开区间 | 时间轴 + 投影平移 |
| explore | t ≥ 0.96（迟滞） | 返回主线 / ESC / 滚回 < 0.90 | OrbitControls |

## 关键约束

1. **单一进度源**：没有 ScrollTrigger pin，没有第二套动画时钟；rAF 里只做 `damp` 与采样。
2. **可逆**：详情开合、章节切换、反向滚动都不重置相机；t 减少即原路返回。
3. **不裁车**：详情只改投影矩阵 `elements[8]`（宽屏 +0.38，窄屏 +0.12），不改变相机朝向。
4. **不重载**：车漆只改材质颜色；热点只移动相机；探索退出只做位姿混合。
5. **失败不黑屏**：模型错误 → 可读提示 + 重新载入；重试复用同一个 Canvas。
