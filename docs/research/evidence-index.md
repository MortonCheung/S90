## 可用于本工程的状态关系

开场并行绘线与资源准备 → 就绪后揭幕 → 四幕由同一滚动进度采样 → 到点改变真实布局 → 延续主线 → 探索交接 → 返回与反向恢复。

笔触推进采用原创有向SVG路径与严格单调进度函数。背景换幕将退出与进入连续混合。空间重布局继续使用现有Grid轨道与实际相机画幅。此处为本工程设计决策，非参考站技术实现断言。

OBSERVED表示本次实际见到，INFERRED表示证据支持的可能机制，UNVERIFIED表示未能完成观察。历史v2取证仅作补充，不冒充本次证据。
