# 四幕产品摄影

镜头唯一数据为 `src/journey/shots.js`，每项包含稳定ID、actId、focusPart、位置、目标、FOV与from/to驻留区间。SHOT_ANCHORS提供holdRange与驻留中点，用于后续截图校准。

清晨由整车转前灯，白天由轮毂转侧面，午后保留既有接近后窗、入窗、仪表台、座椅及退出六个点，黄昏从车尾拉远到探索。ACTS.cameraSequence准确引用这些镜头。

现有静止取景已在阶段01验证，本阶段提取可追溯数据并将滚动行程加长至12.4视口高度，保留相机坐标和六部位构图。没有根据旧版缺陷描述重新发明已正确的车内路径。

进入/退出在两个驻留区间之间由同一平滑函数求值。20,001点采样最大相邻位置差0.01775m，各驻留内位置一致。几何步长测试只证明数据连续，不代替视觉检查。真实浏览器图集包含全部六主题、两个内视与正反返回。
