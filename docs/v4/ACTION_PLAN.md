# 分阶段行动与验收

## 01–03 · 基线、取证和选型

保护当前v3、保存实际开场及六子章节。独立记录参考站可复现动作和证据等级，确认现有工具能承担连续描线。技术选择需服务于同一滚动状态与既有相机。

## 04–08 · 四幕视觉框架

先固定纸、墨、结构线宽和留白，再建立清晨、白天、午后、黄昏状态区间。制作原创建筑SVG，完成真正的连续非线性描线，最后才串联场景换幕。每幕必须实际显示0%、25%、50%、75%、100%的绘制状态，正反一致。

## 09–14 · 镜头、空间和交互闭环

保留六类车辆展示并分配到四幕，提供可追溯的关键帧调参入口。车辆与场景共用锚点和运动方向。检验独立双栏、既有座舱进出、自由探索和返回。此轮终点是从开场到结尾完整可用。

## 15–20 · 专项精修

按顺序处理开场主笔触、真实资源中线与裂幕、几何、漆面与环境、UI和设备性能。每阶段都复查当前功能与相关旧功能，失败先修复。材料数据、渲染帧率与网络时长必须附实测环境。

## 21–22 · 参赛输出与最终交付

用真实新版画面更新三张A3、设计说明、流程图及连续演示。最终核对所有R01–R23、阶段报告、源码构建、生产浏览器、授权和Git记录。已知问题集中列明。

所有阶段的施工顺序均以当前独立手册为准，施工前才读取该手册和必要上游结果。当前进度见阶段报告与全局需求登记。
