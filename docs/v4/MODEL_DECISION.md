# V4 保守模型选择

采用 `s90-preserved-v4.glb`。保留 v3 高质量资源及最初的 14.54MB 版本，不覆盖原资产。

真实原始 GLB 386,347,164 字节。v3 高质量版 73,364,248 字节。本阶段版 66,209,528 字节，减少 9.75%。三者均为 194 个 primitive、3,273,670 个三角面。所有保留的顶点属性经解码后逐元素一致；没有减面、平滑重建或修改切线/法线。只移除任何材质及扩展均未引用的 UV1 / UV2 等 131 组数据。纹理沿用上游 2048 上限版本，原资产仍有部分 4096 贴图，因此不宣称与原资产所有纹理无损一致。

`evidence/stage-17/model-audit.json` 记录网格、材质、扩展、属性类型、纹理尺寸和哈希。`browser-comparison.json` 记录三个版本在同一光照、相机及真实渲染循环下的资源时间、三角面和 RAF 样本。localhost 热缓存与该 Mac 的测量不能代表移动网络。

实际查看三列对比：车门、引擎盖、翼子板和车顶的大面高光连续；轮辐和胎纹、仪表及中控纹理仍在。座椅部分棱面原版也存在，不归咎于当前压缩。五个机位的 v3 与保守版 PNG 像素完全一致。此阶段没有伪称模型变大就改善外观：质量基线沿用已经恢复的高质量几何，得到的是等画质减小资源。下一阶段独立调整材质和环境反射。
