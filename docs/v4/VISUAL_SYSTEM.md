# 阶段04｜建筑手绘视觉系统

当前只建立视觉基础与两张固定机位小样。四幕场景、描线引擎、相机映射仍由后续阶段处理；小样不会由App挂载。

## 设计取向

纯色暖白承托真实PBR汽车；结构用精确直线和少量实色侧面表达，不加纸纹、抖线、霓虹、暗角或大渐变。既有车漆、灯光、接触阴影与双栏布局不变。正文、标题、控件保留现有字体与位置。

- 主结构线1.35px，墨色 `#555d56`；次线0.75px、`#a4aca2`；道路远线0.9px、`#dce0d7`。SVG使用 `vector-effect="non-scaling-stroke"`、直角连接。
- 正文用 `#252b27`，次正文 `#686f66`；浅建筑线只用于空间，不承担正文或按钮文字。
- 一个场景中只用少量中性实色侧面与一处低饱和植栽/材质色。车窗后的线条尽量少，车周围不加描边或发光轮廓。
- 为未来动效登记12px最大环境偏移、1.02最大缩放及240ms界面响应参考；本阶段没有绑定进度，也没有新增动画。

## 两款原创小样

[A：水平庭院](design-study/01-horizontal-residence.svg) 采用左偏的低层立面、退后的廊架与宽前庭；车辆上方大面积留白。它更接近克制的住宅出发场景，经Leader实际对比选择为统一疏密基准。

[B：城市框景](design-study/02-framed-courtyard.svg) 用两侧较高楼体框住中央，空间辨识更强，但边缘窗线和楼体容易与车辆竞争。它作为密度上限对照，不直接成为第二幕正式资产。

两图均为本阶段原创、统一1600×900 viewBox，包含background、architecture、detail、road、foreground语义组。没有引用外站图形、字体或图像。当前比较固定为既有整车 `.075` 镜头；它不是多机位精确空间注册完成的声明。

## 四幕色彩小样

四组静态色板共用同一墨色和线宽。清晨：`#f3f2ec / #e6e9e2 / #d3d9d0`，偏清浅灰绿；白天：`#efefea / #e0e3df / #cbd2cc`，中性灰；午后：`#f1eee7 / #e5ded3 / #d5c8b7`，暖石色；黄昏：`#e6ded5 / #cfc7c0 / #b9aca3`，更深的灰陶色。顺序分别为纸、地、面影。

色板只确定色彩语言，尚未赋予四个正式场景。仅凭这些相近中性色无法保证删去文本就辨识四幕；时间与场景区分还需后续独立建筑轮廓、道路构成及空间密度完成，不提前写四幕验收PASS。

## 地平线与接触规则

1. 地平线是相机眼高的投影，不是轮胎触地点或建筑地脚线。当前 `.075` 机位、1600×900、FOV31°的地平参考约在y238；小样道路与侧立面退深线向这一高度收束。地脚线约y437表示有限距离的建筑基座，不能当作地平线。
2. 正式融合须按当前 `.stage` 实际宽高和相机位置/target/FOV重算，双栏缩放与移动端不能套用本小样的固定屏幕坐标。当前不改相机，也不新增自动标定逻辑。
3. 保留Studio既有GroundingShadow与ContactShadows。轮胎邻近位置应最实，远离接地点自然变淡；不在SVG里再画椭圆“贴纸阴影”，不让建筑面影穿过车底制造第二套光向。
4. 建筑前景先置于透明Canvas底层；少量实体侧面须服从同一光向。避免地面高对比边线刚好切车窗、格栅和轮心；进入座舱与近景融合属于后续阶段，不能用一张全幅建筑覆盖全部镜头。

## 验证与边界

构建：`npm run build`通过，日志见 [build.txt](evidence/stage-04/build.txt)。静态SVG均可独立解析，无外部href、图片、滤镜或渐变。

实际画面对比由 `node tools/v4/visual-study.mjs` 执行：先保存纯色原车，再在实际 `.stage` 的Canvas底层临时注入A/B，输出四组色板，最后移除注入。脚本断言同Canvas、同模型UUID、同机位、无横向溢出、背景无渐变、无console/page/network错误。输出位于 `docs/v4/evidence/stage-04/`，浏览器记录以 `visual-study.json` 为准；若尚无该文件，不把计划动作当作验证完成。

Leader已打开A/B与黄昏实图，选择A。其低矮左偏立面与宽前庭保留了车顶的留白，B仅作为密度上限对照。四幕正式资产和多机位空间融合仍由后续阶段验收。
