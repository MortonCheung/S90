# 车辆与建筑空间

车身位移0、速度0，不以转轮假装行驶。世界地面参考约Y=.022m，接触阴影平面为Y=.023m。实际四胎包围盒最低Y为.02233–.02542m，差约3.1mm属于原模型几何，数据在evidence/stage-11/spatial-check.json。

SceneRegistration仅观察现有主相机，按视口同条件的整车机位标定地平和地面锚点。建筑、道路和前景使用不同深度比例的2.5D缩放与偏移，跟随相机实际取景；没有独立相机动画时钟。原生真实车模和世界空间接触阴影仍由同一Canvas绘制。

背景/建筑/道路/细节/前景的视差权重为.12/.5/.8/.5/1。偏移与缩放设有上限，避免部位特写时二维建筑无限放大。该实现为受控2.5D，完整建筑的三维遮挡与任意角度重建未作为实现声称。

桌面和窄屏正反相同进度的注册数值一致。SVG始终在透明Canvas底层，不覆盖车身或车轮。实际查看整车、侧面、车尾及移动图；车内现有镜头保留，场景淡化与阅读属于阶段13专项融合。
